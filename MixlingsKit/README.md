# MixlingsKit

Swift package for the Mixlings app and widgets (iOS 17+, macOS 14+).

| Product | Purpose |
|---|---|
| `MixlingsGenome` | Genome, hashing, mulberry32 RNG, breeding (port of `engine-ts`). |
| `MixlingsArt` | Pixel-creature renderer (port of `art/render.py`). |

## MixlingsArt

Renders a phenotype to a 32x32 sprite that is **pixel-identical** to the approved
Python renderer `art/render.py` (`render(p, scale=1)`).

```swift
import MixlingsArt

let p = Phenotype(body: 0, eyes: 1, head: 2, pattern: 1, tail: 3,
                  palette: 4, aura: 2, shift: 0, seed: 42)
let buf = MixlingsRenderer.render(p)      // PixelBuffer: width 32, height 32,
                                          // rgba [UInt8], row-major, straight alpha
let big = buf.scaled(by: 8)               // nearest-neighbour upscale (any platform)
let cg  = MixlingsRenderer.cgImage(p, scale: 8)   // Apple platforms (CoreGraphics)
MixlingView(p).frame(width: 128, height: 128)     // SwiftUI, drawn with .interpolation(.none)
```

`Phenotype` mirrors Python `Pheno` (`body, eyes, head, pattern, tail, palette, aura,
shift, seed`). Note the `CGImage` is premultiplied (CoreGraphics requirement); the
`PixelBuffer` is the canonical straight-alpha output. The aura ring (`aura == 2`) is the
only translucent content (alpha 170).

### Portability rules (do not "simplify" these)

- Python `round()` is round-half-to-even: `pyRound` uses `.rounded(.toNearestOrEven)`.
  The aura ring actually hits exact halves (30.5 -> 30, 1.5 -> 2).
- Python float `%` / int `//` / int `%` follow the divisor's sign: `pyMod`, `floorDiv`, `pyIntMod`.
- `colorsys.rgb_to_hls` / `hls_to_rgb` are CPython's code, verbatim, in `Double`.
- Seeds: Python big-int `(seed * k) & 0xFFFFFFFF` == Swift `UInt32(truncatingIfNeeded: seed &* k)`.
- `rnd.choice(sorted(mask))` needs points sorted by (x, then y): `Mask.sortedPoints()`.
- **Highlight tie-break.** `shade_body` uses `sorted(mask, key=...)[:1]`; the key ties for
  every body variant, so CPython picks by *set iteration order*. Since the mask depends
  only on `body`, the winner is a per-body constant recorded in `HIGHLIGHT_TIE_WINNER`
  (verified identical on CPython 3.11, 3.12, 3.13). If `body_mask` or the key changes in
  Python, this table must be regenerated (or Python changed to a deterministic tie-break).

### Verification

- `Tests/MixlingsArtTests/Resources/renders.json` is a copy of `art/golden/renders.json`
  (146 cases, generated by `art/make_golden.py`). `swift test --filter MixlingsArtTests`
  asserts every case byte-for-byte and reports the first differing pixel.
- `art/ts-port/render.ts` is an independent TypeScript port of the same algorithm that the
  Swift mirrors line by line: `node art/ts-port/check.ts` (74/74). Regenerate the golden
  file and re-copy it whenever `art/render.py` changes.
